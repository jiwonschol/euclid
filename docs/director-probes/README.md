# 감독 카드 게임 — 이미지 제작 검증

2026-09-22, [실행 계획](../director_game_plan.md)의 정적 이미지 제작 경로를 시험했다. Higgsfield MCP로 세 장을 생성하고 원본을 내려받았다. 이 폴더는 제작 시안이며 아직 게임에 연결된 출하 자산이 아니다.

| 파일 | 원본 크기 | 배경 | 확인한 용도 |
|---|---|---|---|
| [encounter-style.png](encounter-style.png) | 2688×1520 | 불투명 | 두 선수의 대치, 팀 색과 화풍 참고. 공·배우가 그려져 있어 배경으로 재사용하지 않음 |
| [stadium-empty.png](../../assets/director/stadium-empty.png) | 2688×1520 | 불투명 | 공·경기 중 선수를 제거한 경기장. 골문/지평선의 카메라 보정은 M2에서 수행 |
| [striker-ready.png](../../assets/director/striker-ready.png) | 1744×2336 | 실제 RGBA | 공이 없는 파란 팀 선수. 동일 참조 이미지로 외형·유니폼 유지 |

모델은 `gpt_image_2_5`, 설정은 `flare / high / 2k`, 각 1장이다. 최초 장면 작업 ID를 배경·선수 작업의 참조로 사용했다. 생성 요청마다 3크레딧 견적을 확인했고, 세 작업 후 계정 잔액이 910→901로 변했다. 이번 작업 사용액은 **9/300크레딧**, 남은 승인 예산은 **291크레딧**, 진행 중 유료 작업은 0개다. 개별 최종 영수증은 도구 결과에 없으므로 장부에는 작업별 견적과 전체 잔액 차이를 구분했다.

[generation-ledger.json](generation-ledger.json)에 프롬프트, 입력 참조, 모델 설정, 작업 ID, 원본 URL, 로컬 경로, 파일 해시, 크기, 검토 상태, 비용을 남겼다. 다음 생성도 이번 사용액부터 누적한다. 300은 소진 목표가 아니다.

검증한 것은 다음과 같다.

- 세 원본의 실제 크기와 파일 해시 확인.
- 선수 PNG의 알파 값 0~254, 완전 투명 픽셀 3,029,165개 확인. 단순히 알파 채널이 있다는 표시만으로 판정하지 않음.
- [preview.html](preview.html)에서 실제 브라우저로 경기장 위 합성 및 흰색/어두운 바탕의 경계 확인. 머리·양손·양발이 잘리지 않고 별도 공을 넣을 수 있음.

이 검증은 정적 분리 자산을 쓸 수 있다는 증거다. 움직임, 충돌, 공의 접촉, 게임 규칙, 카드 효과, 재미는 아직 검증하지 않았다. 바닥 기준점은 임시값이며 첫 플레이 장면에서 보정한다. 지원의 화풍 선택도 아직 받지 않았으므로 다른 캐릭터·포즈를 대량 생산하지 않았다.

`preview.html`은 브라우저에서 직접 열 수 있다. 로컬 서버를 쓸 때는 저장소 루트에서 `python3 -m http.server 8649 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8649/docs/director-probes/preview.html`을 연다. 페이지는 이미지를 겹쳐 보여줄 뿐 원본 픽셀을 수정하지 않는다.
