# 감독 카드 게임 실행 상태

## 경기 화면과 박자 변경 (#19)

현재 표현 계약은 [이슈 #19](https://github.com/jiwonschol/euclid/issues/19)다. `37fd3ca`에서 `buzz/19`로 작업했다. 아래 MVP 기록의 24초 국면·82초 시연·예약 후 확정은 이전 동작이다.

READY/HALFTIME 2초, FLOW 2.75초, COMMAND 실제 6초, PRESENT 3.5초, ADVANCE 0.25초다. 선택 외 국면은 6.5초이고, 무입력 28국면의 상한은 354초다. 첫 세 국면은 무입력 39.5초다. 카드 클릭과 숫자 키는 바로 확정한다. FLOW 중 클릭은 관측의 도착 상태를 확정한 뒤 같은 국면을 판정한다.

지시 이름 0.6초 → 기록에 있는 청해 이동 선수 0.8초 → 홍림 0.5초 → 청해 0.55초 → 공/얼굴 0.45초 → 실제 결과 0.6초로 보여준다. 큰 동작 컷은 그 국면의 마지막 행동을 사용하고, 결과 글에는 그 국면의 모든 실제 행동과 지시 이동을 함께 적는다. 앞선 패스가 끝난 뒤 마지막 경합을 보여주는 짧은 요약이다. 성공한 연결은 RECEIVE 사건이 실제 이동 선수와 일치할 때만 쓴다. 지시 이동과 이후 소유권 전환을 함께 표시하되, 기록에 없는 역습 원인은 만들지 않는다.

달리기 시계는 아직 고르지 않은 카드의 시간 보정에 의존하지 않게 `deltaMin / 4`(최대 50 경기초, 반 종료까지 남은 시간 이내)를 먼저 보여준다. COMMAND와 PRESENT에서는 그 숫자를 고정하고 ADVANCE에서 확정된 전체 시간을 공개한다. 화면용 값이며 판정 상태·난수를 바꾸지 않는다. 배경과 전술 필드는 같은 FLOW 기록을 따라 움직인다.

`npm run test:director`의 400경기가 전부 종료했고, G1의 320회 배속·스킵·복원 해시 비교도 통과했다. 무입력 선택창을 포함한 검사 재생 시간은 304~329초다. G7의 옛 500~692초 검사는 새 목표인 360초 이하로 바꿨다. 별도로 이전 main 코드를 직접 불러 100시드 × 4전략의 최종 해시 400개가 전부 같음을 확인했다. `resolve.js`, `cards.js`, `scenario.js`, 에셋 manifest는 변경하지 않았다.

Chromium에서 시드 42 첫 세 국면을 1배속 가상 시계로 0.5초마다 촬영했다(45장). 관찰·선택에 대기 선수 둘이 나온 장면 0장, 세 지시 모두 큰 이름 표시, 연속한 동일 구도의 최장 구간 2초다. 각 국면은 선택 외 6.5초다. 1280×720·1920×1080·375×812에서 가로 overflow와 주요 요소의 가로 경계 이탈 0건, 기본 로드의 JavaScript 예외 0건이다. 지원/유지의 지시와 결과 문구가 실제 기록에 맞게 달랐다. COMMAND에서 시계가 멈추고 막대가 줄어들며, 시간 종료 후 기본 유지로 진행함을 확인했다. 시드 42 무입력 경기의 브라우저 가상 시계를 358.8초까지 진행했을 때 REVIEW·90:00이었다. 실제 벽시계 6분을 재는 측정은 아니다. 일곱 고정 결과 화면도 확인했다.

대표 여섯 컷·선택 비교 사진은 PR에 첨부한다. 새 그림 생성·추가 패키지·배포는 없다. 현재 run/kick/recover 포즈를 사용하므로 슬라이딩 태클과 몸을 비틀어 돌파하는 자세는 표현할 수 없다. 보완한다면 두 팀 각각 태클/돌파 1장씩, 총 4장이 필요하다. 이번에는 만들지 않았다. 사람의 이해·재미 검증은 동준이 별도 이슈로 넘긴다.

실제 브라우저에서 숫자 키 확정·확정 뒤 중복 입력·일시정지와 새로고침 복원·스킵의 판정 상태 유지·하프타임 카드 즉시 확정·동작 줄이기·그림 실패 시 동일 판정도 확인했다. 골 결과는 골문 확대와 실제 공의 좌우/높이, 선방 결과는 기존 장갑 기준점과 공을 사용한다.

## 남은 제품 판단과 다음 한 작업

**다음 작업은 지원의 비교 화면 다섯 장면과 한 경기 평가다.** 5개 중 4개에서 상대 준비·선택 이유·바뀐 행동·대가를 설명할 수 있고, 다시 판단해보고 싶은지 확인한다. 에이전트가 대신 통과시키지 않는다. 이 피드백 전에 L1 이후 콘텐츠·온라인·시즌·배포로 확장하지 않는다.

- 공격 기회가 적다. 400경기 합계 슛821회·골287회, 경기당 약2.05슛·0.72골. 청해209골/홍림78골은 네 입력 전략과 상대 성향을 섞은 값으로 공정성·밸런스의 통과 근거가 아니다. 공격 기회의 빈도, 같은 국면 반복, 선택별 체감 차이를 먼저 평가한다.
- 포즈는 정적 그림 전환이다. 킥은 높은 팔로스루라 지상 타격 접촉이 정확하지 않고 회복 자세는 대기와 비슷하다. 선방은 손 기준점으로 맞췄지만 전체 접촉 애니메이션의 완성을 주장하지 않는다.
- 골문 배경과 일반 배경의 관중 표현이 다르다. 원본83.89MiB도 배포 전 최적화 대상이다.
- 생성 비용의 잔여222크레딧은 자동 소진할 목표가 아니다. 사람 피드백으로 필요한 보완을 결정한다.
- GitHub 단계 이슈는 로컬 구현 상태를 보고하되 코드 게시·사람 평가 전까지 열어둔다.
