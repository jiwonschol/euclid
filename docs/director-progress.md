## 남은 제품 판단과 다음 한 작업

**다음 작업은 지원의 비교 화면 다섯 장면과 한 경기 평가다.** 5개 중 4개에서 상대 준비·선택 이유·바뀐 행동·대가를 설명할 수 있고, 다시 판단해보고 싶은지 확인한다. 에이전트가 대신 통과시키지 않는다. 이 피드백 전에 L1 이후 콘텐츠·온라인·시즌·배포로 확장하지 않는다.

- 공격 기회가 적다. 400경기 합계 슛821회·골287회, 경기당 약2.05슛·0.72골. 청해209골/홍림78골은 네 입력 전략과 상대 성향을 섞은 값으로 공정성·밸런스의 통과 근거가 아니다. 공격 기회의 빈도, 같은 국면 반복, 선택별 체감 차이를 먼저 평가한다.
- 포즈는 정적 그림 전환이다. 킥은 높은 팔로스루라 지상 타격 접촉이 정확하지 않고 회복 자세는 대기와 비슷하다. 선방은 손 기준점으로 맞췄지만 전체 접촉 애니메이션의 완성을 주장하지 않는다.
- 골문 배경과 일반 배경의 관중 표현이 다르다. 원본83.89MiB도 배포 전 최적화 대상이다.
- 생성 비용의 잔여222크레딧은 자동 소진할 목표가 아니다. 사람 피드백으로 필요한 보완을 결정한다.
- GitHub 단계 이슈는 로컬 구현 상태를 보고하되 코드 게시·사람 평가 전까지 열어둔다.
