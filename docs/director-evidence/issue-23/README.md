# #23 경기 화면 검증

이 브랜치는 검증 사진 전용이다. `main`으로 머지하지 않는다. 현재 이름표 검증 대상은 `bd8096eeb1c46afcd80f6c30ad7feacf0f2b03a5`다. 최초 구현은 `f42bda359abb90721d16898bae9431c9283fa98d`, 최초 비교 기준은 `1a7b8978af77e69837daf5d238e01e3b4b56373e`다. Chromium/Playwright 1.63.0에서 `http://localhost:8653/director.html` 및 `director-lab.html`을 실행했다. Browser plugin not available.

`after/report.json`은 현재 코드의 전수 이름표 계측이다. `LABEL_MATRIX.cjs`가 실제 drawActor의 이름표 fillRect를 기록하고 manifest contentBounds에 그리기 변환을 적용해 배우 bbox를 계산한다. 사각형 단위는 캔버스 기준 CSS px다. 메인 render가 DOM 문구를 갱신한 뒤 microtask에서 HUD·자막 사각형을 읽는다. 이름표가 없는 실루엣도 이름표가 피해야 하는 배우 사각형에 포함한다.

최초 보고의 “상단 안내와 겹치지 않는다”는 선택 컷에서만 확인한 것을 넓혀 쓴 잘못된 주장이다. `f42bda3`의 1280 달리기 이름표는 화면 y80.5–104.5여서 HUD y76–110.3에 가려졌다. 현재 코드는 실제 HUD 아래 6px부터 이름표 공간을 확보하도록 배우 높이를 제한한다. 모바일 얼굴·넓은 선택 컷의 실루엣도 줄여 이름표를 가리지 않는다.

104개 브라우저 실행(네 폭 × 일반/동작 줄이기 × 기본 경기·다섯 카드·일곱 결과)에서 15,794프레임과 이름표 13,485개를 검사했다. 아래 수는 이름표를 그린 프레임 수다. 모두 선수·실루엣·HUD 셋·자막·다른 이름표와 겹침 0건, 캔버스 이탈 0건, JavaScript 예외 0건이다. 이동 컷은 최대 두 선수의 이름표를 동시에 검사했다.

1280 달리기 이름표는 화면 x597–683, y116.30–140.30으로 HUD 아래 6px다. ADVANCE 대표 이름표는 화면 x597–683, y120.65–144.65다. 각 컷의 사진은 `after/labels/<폭>-<컷>.png`에 있다. 재작업 전 보고서·사진은 고정 커밋 `a57282b808db0a0a25f0f7e47deb0af25ff5cebd`에서 읽는다. 아래 이름표 외 지표는 최초 구현 `f42bda3`에서 측정했고 이번 재작업에서 그 동작은 변경하지 않았다.

이름표 아래와 자신의 배우 위 사이 6px. 모바일 카드 높이 165→190px, 제목 15→14px, 설명 10→12px. 공격·수비 여섯 카드의 문구 bbox가 카드 안에 있으며 잘림과 가로 overflow가 없다.

ADVANCE 구간을 약 16ms마다 관측한 결과 세 폭에서 각각 16개 프레임을 확인했다. 수정 전 배우 0명 프레임 48개, 수정 후 0개다. 선수 없이 빈 구장만 보이던 전개 단계에 실제 소유자 또는 공에 가까운 소유 팀 선수를 그린다.

달리기 1.35초 지점의 배경 반복 경계는 1280 폭의 x≈1167, 1920 폭의 x≈1751이었다. 배경 두 장의 좌표에는 틈이 없지만 그림의 좌우 끝이 이어지지 않았다. 수정은 한 장의 너비를 1.18배로 그려 이동한다. 기존 경계 위치에서 상단 20% 세로 픽셀 열의 평균 RGB 절댓값 차이는 1280에서 약 74→1.08, 1920에서 73.90→0.54로 줄었다. 수정 후 주변 열은 각각 0.60~1.01, 0.48~0.63이다. 단일 배경이 화면 왼쪽과 오른쪽을 모두 덮으며 반복 이음새가 없다.

비교 화면 자막은 처음부터 실제 문구를 표시하고 ¼배속으로 재생한다. 20ms 관측에서 지시 2380ms, 이동 3200ms, 상대 2000ms, 우리 2220ms, 공 1780ms, 결과 2400ms였다. 결과 문구는 ADVANCE에서 정지한 뒤에도 유지된다. 본 게임의 재생 시간과 판정은 바뀌지 않는다.

`EUCLID_23_WALL.json`은 가상 시계를 쓰지 않은 기본 시드 42, 무입력·무스킵·1배속 한 경기다. 하프타임 162941ms, 종료 327567ms, 26국면, 후반 90:00, 점수 0:0, JavaScript 예외 0건. `EUCLID_23_HALFTIME.json`은 실제 브라우저의 후반 시작 버튼→FLOW, 중앙 차단 카드→PRESENT 및 모바일 수비 카드 계측이다.

404 테스트는 실제 런타임 파일 `card-support.webp`, `keeper-dive-green.webp` 요청을 차단했다. 카드 img는 기호로 교체되고 누락 안내가 보인다. 선방 컷의 대체 `keeper-green-ready` bbox는 1280×720에서 선수 기준점 (640,324)을 포함한다. 두 결함은 기준 커밋에서도 재현되지 않았고 #15를 닫아도 된다.

`EUCLID_23_MUTATION.log`는 상대/우리 컷 순서를 바꿨을 때 `sim/director-ui.mjs`가 실제 main.js 버튼·프레임 루프를 실행해 순서 단언에서 실패한 결과다. 테스트 어댑터는 DOM과 그리기만 대체하고 DirectorMatch·카드 합법성·시간·projection은 실제 모듈을 쓴다.

`EUCLID_23_DISABLED_MUTATION.log`는 클릭 직전에 카드를 강제로 disabled로 바꿔 `FLOW click must immediately commit`에서 실패한 결과다. 어댑터도 브라우저처럼 비활성 버튼의 onclick을 실행하지 않도록 고쳤다. 모바일 크기 분기도 CSS와 같은 `<=740` 경계를 사용한다.

기존 #19 PNG 12장은 코드 브랜치에서 제거했지만 `d7a62dcb1d1d8212604f3adaca854c7d26a4e58c`의 URL은 12개 모두 HTTP 200이다. 이전 사진은 그 커밋에서 복구할 수 있다. 원본 경기 에셋과 판정 코드는 수정하지 않았다.
